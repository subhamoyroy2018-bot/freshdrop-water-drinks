# FreshDrop - Water & Cold Drinks Business

## Run on your computer
1. Install Node.js.
2. Open this project folder in Terminal/CMD.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

## Free live hosting
This Node/Express project can be deployed to a free-tier hosting provider that supports Node.js, or the frontend can be hosted separately on a static host. For a real business, replace the sample phone/email and connect a proper database/payment system.

## API
- POST `/api/orders` - create an order
- GET `/api/orders` - list orders (add authentication before production)
